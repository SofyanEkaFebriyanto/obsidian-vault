## What changed — double-submit guard
1. **Client** (`resources/views/checkout.blade.php`):
   - Form: `x-ref="form"` + `@submit.prevent="submitOnce"`.
   - Alpine: state `submitting` + method `submitOnce()` → cek flag, set true, `this.$refs.form.submit()` (native submit dipertahankan biar validasi HTML + CSRF jalan).
   - Button: `:disabled="submitting"` + `:class` opacity/cursor + `x-text` jadi "Memproses…".
2. **Server** (`app/Http/Controllers/CheckoutController.php`):
   - Set `session('last_order_at')` + `session('last_order_number')` setelah order berhasil dibuat.
   - Awal `store()`: kalau `last_order_at` < 10 dtk lalu → redirect ke order yg sama (bukan bikin duplikat).
3. **Test** `tests/Feature/DoubleSubmitCheckoutTest.php` 2/2: resubmit <10dtk → 1 order tetap; >10dtk → boleh bikin order ke-2.
